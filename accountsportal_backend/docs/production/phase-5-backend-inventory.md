# Phase 5 Backend Inventory

## Solution Projects
- **TexasAccountsPortal.Api**: REST API controllers, filters, middleware, dependency injections.
- **TexasAccountsPortal.Application**: Core interfaces, application logic/commands/queries, DTOs.
- **TexasAccountsPortal.Infrastructure**: EF Core DB contexts, repositories, operational-to-GL posting services, financial services, payroll service, token/identity services.
- **TexasAccountsPortal.Domain**: Pure business entities, aggregates, enums, rules.
- **TexasAccountsPortal.Contracts**: Payload definitions shared across API boundaries.
- **TexasAccountsPortal.UnitTests**: Unit tests for domain models, calculation engines.
- **TexasAccountsPortal.IntegrationTests**: Integration tests for endpoints, databases, full payroll lifecycle.
- **TexasAccountsPortal.ArchitectureTests**: NetArchTest checks enforcing clean architecture dependencies.
