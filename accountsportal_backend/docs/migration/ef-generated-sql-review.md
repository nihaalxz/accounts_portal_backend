# EF Core Generated SQL Review

This document provides a detailed review of the SQL schema generated by the initial Entity Framework Core migration (`InitialCreate`).

---

## 1. Column Precision & Types

* **Financial Decimals**:
  - Verified that all monetary and ledger balance fields use the **`decimal(19,3)`** format to ensure range safety for multi-million dollar balances and accurate sub-cent fractions.
  - Tables verified: `accounts`, `banks`, `suppliers`, `agents`, `transactions`, `balance_corrections`, `journals`, `staff_payroll_records`.
* **RowVersion Concurrency Mappings**:
  - Mapped as `rowversion` columns (mapped to the internal `rowversion` SQL Server datatype).
  - Tables verified: `accounts`, `banks`, `suppliers`, `agents`.

---

## 2. Uniqueness & Index Verification

* **Idempotency Safeguards**:
  - A unique composite index `IX_idempotency_records_Scope_Key` is configured on `idempotency_records(Scope, Key)`. This ensures hardware-level protection against duplicate requests.
* **Service Session Security**:
  - A unique index `IX_refresh_tokens_TokenHash` is mapped on `refresh_tokens(TokenHash)` to prevent collision or rotation tampering. An index is also declared on `UserId` for query speed.
* **Business Code Constraints**:
  - `IX_users_Email` on `users(Email)` is `UNIQUE`.
  - `IX_suppliers_Code` on `suppliers(Code)` is `UNIQUE`.
  - `IX_banks_AccountNumber` on `banks(AccountNumber)` is `UNIQUE`.
  - `IX_agents_SalesmanId` on `agents(SalesmanId)` is `UNIQUE WHERE [SalesmanId] IS NOT NULL`.

---

## 3. Index Optimization for Background Tasks

* **Outbox Claiming Indexes**:
  - The index `IX_outbox_messages_Status_AvailableAt` is configured on `outbox_messages(Status, AvailableAt)`. This enables high-frequency background claims to run without scanning the table.
* **Ledger Query Indexes**:
  - `IX_transactions_Status`
  - `IX_transactions_TransactionType`
  - `IX_transactions_ReferenceType_ReferenceId`
  - These support rapid filter queries on the public ledger endpoints.
